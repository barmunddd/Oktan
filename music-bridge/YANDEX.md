# Яндекс Музыка / OKTAN

Управление официальным приложением Яндекс Музыки через Windows Media Sessions. Учётные данные, куки и токены аккаунта не нужны. Подпиской пользуется само приложение Яндекса.

## Запуск

1. Открой приложение Яндекс Музыки на ПК и включи трек хотя бы один раз.
2. Запусти `start_yandex.py` двойным щелчком либо командой:

   ```powershell
   python "C:\Users\Ssweur\Documents\ChatGPT\oktan-client\music-bridge\start_yandex.py"
   ```

3. Запусти последнюю версию OKTAN. В меню: **Settings → Music → Yandex Music → Connect**.
4. Доступны Play, Pause, Next и Previous. Stop использует настоящую остановку, если приложение разрешает; иначе ставит на паузу и пытается сбросить позицию. Если сброс не поддерживается, об этом написано явно.

Нужен Windows 10 версии 1809 или новее / Windows 11, Python 3.11+. При первом запуске создаётся отдельное окружение `work/music-venv` и устанавливаются зависимости из `requirements-yandex.txt`. Для другого исполнителя передай `--workspace "ПУТЬ_К_WORKSPACE"`. По умолчанию — `%LOCALAPPDATA%\Xeno\workspace`.

Окно модуля оставь открытым; `Ctrl+C` его останавливает. Выгрузка клиента и завершение модуля не останавливают твою музыку автоматически. Автозапуск после перезагрузки Windows не устанавливается.

## Поиск

Поле принимает исполнителя, группу или песню. **Search ↗** возвращает ссылку на результаты поиска на `music.yandex.ru`. Если исполнитель поддерживает `openurl`, откроется страница сервиса; иначе ссылка копируется для открытия вручную. Выбор и запуск найденного трека выполняются в самом сервисе. Это не встроенный каталог Яндекса и не автоматическая выдача треков по API.

## Работа модуля

Сервис слушает только `127.0.0.1:8975`, проверяет Host и случайный pairing-заголовок, не разрешает запросы от веб-страниц. Pairing-файл `Oktan-yandex-bridge.json` хранится только в workspace, удаляется при штатном завершении и не должен публиковаться. В нём нет токена Яндекса.

Управление допускается только сессиями с идентификатором приложения Яндекс Музыки, а не текущим произвольным плеером Windows. При нескольких одинаковых сессиях требуется закрыть лишние. Если плеер не найден — включи трек в приложении и повтори Connect. Статус опрашивается раз в три секунды только при открытой музыкальной панели. Нет постоянного поиска по каталогу и запросов на каждый кадр.
