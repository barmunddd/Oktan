# Яндекс Музыка / OKTAN

Управление официальным приложением Яндекс Музыки через Windows Media Sessions. Учётные данные, куки и токены аккаунта не нужны. Подпиской пользуется само приложение Яндекса.

## Запуск

1. Открой приложение Яндекс Музыки на ПК и включи трек хотя бы один раз.
2. Запусти `start_yandex.py` двойным щелчком либо командой:

   ```powershell
   python "C:\Users\Ssweur\Documents\ChatGPT\oktan-client\music-bridge\start_yandex.py"
   ```

3. Запусти последнюю версию OKTAN. В меню: **Settings → Music → Yandex Music → Connect**.
4. Доступны Play, Pause, Next и Previous. Stop использует настоящую остановку, если приложение разрешает; иначе ставит на паузу и пытается сбросить позицию. Если сброс не поддерживается, об этом написано явно.

Нужен Windows 10 версии 1809 или новее / Windows 11, Python 3.11+. При первом запуске создаётся отдельное окружение `work/music-venv` и устанавливаются зависимости из `requirements-yandex.txt`. Для другого исполнителя передай `--workspace "ПУТЬ_К_WORKSPACE"`. По умолчанию — `%LOCALAPPDATA%\Xeno\workspace`.

Окно модуля оставь открытым; `Ctrl+C` его останавливает. Выгрузка клиента и завершение модуля не останавливают твою музыку автоматически. Автозапуск после перезагрузки Windows не устанавливается.

## Поиск

Поле принимает исполнителя, группу или песню. **Search ↗** возвращает ссылку на результаты поиска на `music.yandex.ru`. Если исполнитель поддерживает `openurl`, откроется страница сервиса; иначе ссылка копируется для открытия вручную. Выбор и запуск найденного трека выполняются в самом сервисе. Это не встроенный каталог Яндекса и не автоматическая выдача треков по API.

## Музыкальная плашка

После Connect музыка появляется внутри существующего Dynamic Island. При смене трека строки плавно сменяются, Pause меняет кнопку, Stop приглушает и сжимает блок. Кнопки Previous, Play/Pause, Next и Stop управляют приложением. В раскрытом островке музыкальный ряд остаётся сверху, а время, киллы и бинды сохраняются. Music Island можно выключить в настройках Dynamic Island. Фоновые частицы не добавляются.

Без текста песни показываются реальные название и исполнитель. Для своих синхронных строк положи **UTF-8 файл `Oktan-lyrics.lrc`** в workspace исполнителя и нажми **Reload LRC** в панели Яндекс Музыки. Обязателен заголовок с точным названием текущего трека:

```text
[ti:Название текущего трека]
[00:00.00]Первая строка вашего текста
[00:05.50]Следующая строка вашего текста
```

Это пример формата, не текст существующей песни. Поддержаны несколько меток на строку и `[offset:100]` (смещение в миллисекундах), до 1200 меток и 128 КиБ. Полоса отражает интервал до следующей строки, а не распознанные тайминги отдельных слов.

Если Windows передаёт позицию трека, строки следуют ей. Когда позиция недоступна, запусти трек с начала и одновременно нажми **Sync 0:00**. Это ручная синхронизация: локальный таймер приостанавливается вместе с музыкой, при смене трека привязка сбрасывается. После перемотки нужна повторная синхронизация. Тексты автоматически не скачиваются из Яндекса.

Статус обновляется раз в три секунды и при включённом музыкальном островке, даже если меню скрыто. После 12 секунд без ответа модуля плашка возвращается к обычному HUD. Переходы используют Motion; с Light Menu состояние статичное.

## Доступ модуля

Сервис слушает только `127.0.0.1:8975`, проверяет Host и случайный pairing-заголовок, не разрешает запросы от веб-страниц. Pairing-файл `Oktan-yandex-bridge.json` хранится только в workspace, удаляется при штатном завершении и не должен публиковаться. В нём нет токена Яндекса.

Управление допускается только сессиями с идентификатором приложения Яндекс Музыки, а не текущим произвольным плеером Windows. При нескольких одинаковых сессиях требуется закрыть лишние. Если плеер не найден — включи трек в приложении и повтори Connect. Статус опрашивается раз в три секунды при открытой музыкальной панели или включённом музыкальном островке. Нет постоянного поиска по каталогу и запросов на каждый кадр.

При проверке на этом ПК обнаружен `A025C540.Yandex.Music_vfvw9svesycw6!App`. Поддержка Pause/Next/Previous подтверждена сведениями Windows; отдельные Stop и перемотка не поддерживались. Никаких команд реальному треку во время проверки не отправляли.
